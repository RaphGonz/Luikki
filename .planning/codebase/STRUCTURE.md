## Directory Purposes

**`src/comiccolor/`:**
- Purpose: Main Python package
- Contains: All source code, organized by concern (model, segmentation, extraction, research)
- Key files: `cli.py` (entry), `model/entities.py` (data model), `segmentation/segmenter.py` (region segmentation)

**`src/comiccolor/model/`:**
- Purpose: §3 data model, exact region storage, and SQLite persistence
- Contains: Domain objects (entities.py), label map I/O (masks.py), database schema and CRUD (store.py)
- Key files: 
  - `entities.py` — `Region`, `PaletteEntry`, `Panel`, `Page`, `Volume`, `Series`, `ProtectedMask`, enums
  - `masks.py` — `region_stats()`, `check_coverage()`, `save_label_map()`, `load_label_map()`
  - `store.py` — `Store` class, SCHEMA with foreign keys, no-RGB-on-region enforcement

**`src/comiccolor/segmentation/`:**
- Purpose: Deterministic geometric stages of the pipeline
- Contains: Raster I/O, panel detection, line closure, region segmentation (two implementations)
- Key files:
  - `preprocess.py` — `load_line_art()`, `ink_fraction()`, `estimate_line_width()`
  - `panels.py` — `segment_panels()`, gutter-based detection via trapped-ball
  - `closure.py` — `close_line_gaps()`, morphological line repair
  - `trappedball.py` — `trapped_ball_segment()`, expanding disc search
  - `segmenter.py` — `Segmenter` protocol, `TrappedBallSegmenter`, `LineFillerSegmenter` (interface to third_party/LineFiller)

**`src/comiccolor/extract/`:**
- Purpose: Line extraction, the swappable seam for §7 domain adapters
- Contains: Protocol and implementations for learned vs. no-op extractors
- Key files:
  - `base.py` — `LineExtractor` protocol, `ExtractionResult` dataclass
  - `manga_line.py` — `MangaLineExtractor` wraps third_party/MangaLineExtraction model
  - `passthrough.py` — `PassthroughExtractor` returns original line art unchanged

**`src/comiccolor/spike/`:**
- Purpose: Research spikes for §P3 and §P3 follow-up (AB testing)
- Contains: Pipeline orchestration, metrics collection, visualization for debug
- Key files:
  - `p3.py` — Region-count measurement across extractors, thresholds, closures; calls all segmentation/extraction layers
  - `ab.py` — Compare our TrappedBall vs. LineFiller; resumes on interrupt
  - `visualise.py` — `colourise_labels()` (random RGB per label), `overlay_panels()` (debug renders)

**`tests/`:**
- Purpose: Unit tests for each layer
- Contains: Test files organized by module
- Key files:
  - `test_masks.py` — Label map storage, region_stats, coverage checks
  - `test_panels.py` — Panel segmentation edge cases
  - `test_trappedball.py` — Region segmentation correctness
  - `test_store.py` — SQLite CRUD, foreign keys, schema
  - `test_hatching.py` — Hatching-specific segmentation behavior

**`third_party/`:**
- Purpose: Vendored dependencies
- Contains: LineFiller (hepesu/LineFiller, MIT) and MangaLineExtraction (model + weights)
- Generated: `__pycache__` after first import
- Committed: Yes, required for reproducibility

**`test_pages/`:**
- Purpose: Sample pages for spike measurements
- Contains: PNG images from different comic styles (manga, ligne claire, franco-belgian, etc.)
- Generated: No
- Committed: Yes (manually added during P3 validation)

**`reports/`:**
- Purpose: Output from research spikes
- Contains: JSON reports, markdown summaries, debug renders (per condition/segmenter)
- Generated: Yes (created by `comiccolor p3` and `comiccolor ab` commands)
- Committed: No (gitignore)

**`.planning/codebase/`:**
- Purpose: GSD codebase analysis documents
- Contains: ARCHITECTURE.md, STRUCTURE.md (and future CONVENTIONS.md, TESTING.md, etc.)
- Generated: Yes (by `/gsd-map-codebase` agent)
- Committed: Yes (reference for future agents)

## Key File Locations

**Entry Points:**
- `src/comiccolor/cli.py`: Main CLI, dispatches to `spike/p3.py:run_p3()` or `spike/ab.py:run_ab()`
- `pyproject.toml`: `[project.scripts]` defines `comiccolor = "comiccolor.cli:main"`

**Configuration:**
- `pyproject.toml`: Package metadata, Python version (>=3.11), dependencies (numpy, opencv, scipy, pillow)
- `.pytest.ini_options`: Test path (`tests/`) and default pytest settings

**Core Logic:**
- **Region Segmentation**: `src/comiccolor/segmentation/segmenter.py` (protocol) + `trappedball.py` (our impl)
- **Panel Detection**: `src/comiccolor/segmentation/panels.py:segment_panels()`
- **Line Extraction**: `src/comiccolor/extract/base.py` (protocol), `manga_line.py` (learned)
- **Data Model**: `src/comiccolor/model/entities.py` (domain objects)
- **Label Map Queries**: `src/comiccolor/model/masks.py:region_stats()`, `check_coverage()`
- **Persistence**: `src/comiccolor/model/store.py:Store` class with SQLite backend

**Testing:**
- `tests/test_masks.py`: Label map invariants
- `tests/test_panels.py`: Panel detection edge cases
- `tests/test_trappedball.py`: Region segmentation correctness

## Naming Conventions

**Files:**
- Python modules: lowercase with underscores (`segmentation/panels.py`, `extract/manga_line.py`)
- Test files: `test_<module>.py` (e.g., `test_masks.py` tests `model/masks.py`)
- Generated output: `<spike_name>.json`, `<spike_name>.md` (e.g., `p3.json`, `ab.md`)

**Directories:**
- Layer directories: lowercase plural nouns (`model/`, `segmentation/`, `extract/`, `spike/`)
- Output directories: spike name or condition name (`reports/p3/`, `reports/ab/`, `reports/p3/raw/`)

**Functions:**
- Snake_case for functions and methods (`load_line_art`, `segment_panels`, `region_stats`)
- Verbs for actions: `load_`, `save_`, `segment_`, `close_`, `check_`, `estimate_`

**Classes:**
- PascalCase for classes (`Series`, `Volume`, `Page`, `Panel`, `Region`, `PaletteEntry`, `Segmenter`)
- `<Name>Segmenter` for segmentation implementations (`TrappedBallSegmenter`, `LineFillerSegmenter`)
- `<Name>Extractor` for extraction implementations (`MangaLineExtractor`, `PassthroughExtractor`)
- `<Name>Params` for parameter dataclasses (`PanelParams`, `SegmentationParams`, `ClosureParams`)

**Types & Protocols:**
- `<Name>Result` for output dataclasses (`PanelResult`, `ConditionResult`, `PageResult`, `ExtractionResult`)
- `<Name>Kind` or `<Name>Status` for enums (`ProtectedKind`, `RegionStatus`)

## Where to Add New Code

**New Feature (e.g., Cobra colour proposer for §1.6):**
- Primary code: New module `src/comiccolor/colour/` with `cobra.py` (wraps model), `snapping.py` (CIELAB snap per §1.7)
- Tests: `tests/test_cobra.py`, `tests/test_snapping.py`
- Integration: Extend `spike/p3.py` to call new colour stages after segmentation; store results in region confidence/status
- Data model: Use existing `Region.confidence`, `Region.status`, `Region.palette_entry_id` (no schema change needed)

**New Segmentation Implementer (e.g., SAM-based, future Tier 3 adapter):**
- Primary code: New class in `src/comiccolor/segmentation/segmenter.py` implementing `Segmenter` protocol
- Example: `class SamSegmenter: def segment(line_mask, protected=None) -> np.ndarray: ...`
- Tests: `tests/test_segmentation.py` (new) comparing against ground truth
- Integration: Instantiate in `spike/ab.py:_segmenters()` to add to comparison

**New Line Extractor (e.g., Tier 3 domain adapter for American comics):**
- Primary code: New class in `src/comiccolor/extract/` (new file `american_comics.py`) implementing `LineExtractor` protocol
- Example: `class AmericanComicsExtractor: def extract(grey) -> ExtractionResult: ...`
- Tests: `tests/test_extract.py` (new) if shared, or `tests/test_american_comics.py`
- Integration: Instantiate in `spike/p3.py:_build_extractors()` to add to condition list

**New Tier 1 Pipeline Stage (e.g., §1.2 bubble detection, §1.9 region editor):**
- Primary code: New module `src/comiccolor/<stage_name>/` (e.g., `src/comiccolor/protection/` for bubbles)
- Protocol: Define interfaces if multiple implementations expected (e.g., `BubbleDetector` protocol)
- Tests: Mirror module structure (`tests/test_<stage_name>.py`)
- Integration: Call from `spike/p3.py` or future Tier 1 orchestrator; pass `ProtectedMask[]` to segmenters

**New Test:**
- Co-located with the code being tested: `tests/test_<module>.py`
- Use pytest fixtures for common setup (e.g., synthetic label maps, test pages)
- Check invariants, not just values: exhaustiveness, exclusivity, coverage

**Utility Functions (shared helpers):**
- If used by multiple modules: `src/comiccolor/utils.py` or thematic submodule
- Example: colour space conversions (RGB ↔ CIELAB) might go in `src/comiccolor/colour/util.py`
- Import as: `from comiccolor.utils import <func>` or `from comiccolor.colour.util import <func>`

**Vendored Dependencies:**
- Add subdirectory to `third_party/` (e.g., `third_party/NewLibrary/`)
- Do not edit vendored code unless critical; prefer wrapping in an adapter
- Example: `segmenter.py:LineFillerSegmenter` wraps `third_party/LineFiller/linefiller/` without modification
- Document in top-level comment why it's vendored (e.g., "no PyPI release", "customizations needed")

## Special Directories

**`third_party/LineFiller/`:**
- Purpose: hepesu/LineFiller, trapped-ball reference implementation (MIT license)
- Generated: `log/app.log` created on first import (suppressed by `segmenter.py:_install_quiet_logger()`)
- Committed: Yes
- Note: Vendored to ensure reproducibility; both our TrappedBallSegmenter and this are compared in AB spike

**`third_party/MangaLineExtraction/`:**
- Purpose: Line extraction model and weights
- Generated: `pytorchResults/`, `pytorchTestCases/` caches (not committed)
- Committed: Yes (model code + erika.pth weights)
- Note: Licensed MIT; acknowledged as Cobra dependency per spec §2 (P2 resolved)

**`reports/`:**
- Purpose: Output staging area for spikes
- Generated: Yes, entirely
- Committed: No (.gitignore)
- Structure: `reports/<spike_name>/` with `<spike_name>.json`, `<spike_name>.md`, condition-specific subdirs with debug PNGs

**`.planning/codebase/`:**
- Purpose: GSD agent output (codebase documentation)
- Generated: Yes (by `/gsd-map-codebase`)
- Committed: Yes
- Contents: ARCHITECTURE.md, STRUCTURE.md, CONVENTIONS.md, TESTING.md, CONCERNS.md (as applicable)

**`__pycache__/`:**
- Purpose: Python bytecode cache
- Generated: Yes (on import)
- Committed: No (.gitignore)
- Location: One per directory containing `.py` files

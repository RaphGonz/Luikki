<objective>
Lay the web contract for both geometry routers before either grows a route: the bounded Pydantic
types that stop hostile geometry at the door, the response models, the two router modules with
their ownership helpers and response adapters, and their registration in `create_app()`.

Purpose: Phase 2 adds the first write endpoints that accept artist-supplied geometry. Every
vertex list eventually reaches `cv2.fillPoly`, which allocates and writes based on those numbers.
Bounding them at the boundary — the same way Phase 1's `RGBChannel = Annotated[int, Field(ge=0,
le=255)]` bounds colour — is cheaper and more reliable than defending inside OpenCV. Registering
both routers here also means plans 02-08 and 02-09 can add routes to their own files in parallel
without either touching `app.py`.

Output: `schemas.py` additions, two registered-but-routeless router modules, and passing tests
that a malformed body is refused.

Implements D-20 (page-scoped mask contracts) and supports D-19 (the delete-returns-list shape
routine deletion needs).
</objective>

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-2-01 | Denial of Service | `Polygon` bodies reaching `cv2.fillPoly` | mitigate | `Polygon = Annotated[list[Vertex], Field(min_length=3, max_length=512)]` and `PixelCoord = Annotated[int, Field(ge=0, le=100_000)]` refuse oversized and out-of-range geometry with 422 before any handler or OpenCV call runs; pinned by `tests/test_web/test_geometry_schemas.py` |
| T-2-02 | Tampering / Information Disclosure | `panel_id` / `mask_id` supplied by the client | mitigate | `_get_owned_panel` and `_get_owned_protected_mask` resolve the row, then re-check ownership through `get_owned_page`, mirroring Phase 1's `get_owned_volume` / `_get_owned_page` chain; a stale id from a closed project answers 404 |
| T-2-04 | Spoofing | A new route bypassing Phase 1's origin check | mitigate | Both routers are registered inside `create_app()` under the `/api` prefix the `_reject_foreign_origins` middleware scopes to; a route-enumeration test asserts every new path starts with `/api` |
| T-2-19 | Injection | SQL built inside a router | mitigate | Routers call `Store` methods only; a grep for SQL keywords under `web/routers/` is an acceptance criterion and must stay empty |
| T-2-20 | Tampering | `ProtectedKind` supplied as a free-form string | mitigate | `ProtectedMaskCreateRequest.kind` is typed as the real `ProtectedKind` enum imported from `..model`, not a string union that could drift from `entities.py` |
</threat_model>
